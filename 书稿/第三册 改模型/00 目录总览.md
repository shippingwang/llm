# 第三册 大模型后训练与智能体系统

**读者**：已经理解现代 LLM 架构，也知道模型如何训练和部署，现在要把通用基座改成真正解决自己问题的模型与系统。

**读完能做到**：

1. 独立设计 instruction 数据，SFT，LoRA/QLoRA，偏好优化与可验证强化学习方案。
2. 解释 DPO，PPO，GRPO 等方法优化什么，数据长什么样，何时会失败。
3. 讲清思维链如何进入训练与推理，以及测试时计算和训练期优化的分界。
4. 设计 RAG，工具，Skill 与 Agent，并判断该改权重，改上下文还是改运行循环。
5. 知道生成模型与决策模型（如 Jev）各自适合哪类判定。

## 三册边界

- 第一册 **做模型**：模型由哪些模块组成，为什么采用这些结构。
- 第二册 **跑模型**：怎样在真实硬件上训练，推理和部署。
- 第三册 **改模型**：怎样改变目标任务上的行为，以及怎样把能力接到系统里。

第三册里的改有三种强度：

1. **改上下文**：提示词，结构化输出，RAG，工具和 Agent，不改权重。
2. **改一小部分权重**：LoRA，Adapter，低成本适配任务。
3. **改全部权重**：继续预训练，SFT，偏好优化和强化学习。

## 贯穿全书的三份产物

- **行为规格表**：每个能力的输入，期望输出，不可接受行为，指标与最低门槛。
- **失败样本库**：错误类型，触发条件，模型版本和是否已修复。
- **实验卡片**：数据版本，模板，训练方法，超参，权重版本，推理配置和完整评测结果。

每一轮迭代都要更新这三份东西。没有它们，第三册的技术会退化成一串不可复现的经验。
