# 第 5 章 奖励模型

## 5.1 损失

奖励模型把 prompt 和回答打成标量 \(r_\phi(x,y)\)。成对数据上

\[
\mathcal{L}_{\mathrm{RM}}
=-\log\sigma\bigl(r_\phi(x,y_w)-r_\phi(x,y_l)\bigr).
\]

损失只要求赢家高于输家。分数没有绝对单位，两个模型的 3.2 不能比较。报告成对排序准确率。另做一批故意改过长度，事实和诱导句的样本，看分数是否跟着改。

权重从 SFT 初始化，末尾换标量头。生成式打分模型也可以用，在线训练时标量头更方便对一整批轨迹算分。

## 5.2 分量

正确性，安全，简洁合成一个数之后，高的一维可以盖住低的一维。泄漏和越权做成硬条件，触发即失败，不进加权。主奖励用任务结果。格式和长度只加小的附加项，每一项单独记日志。

训练曲线上的总奖励上升，独立集合上的正确率不升，就停。附加项里哪一项在涨，从分项日志里看。

## 5.3 捷径

奖励模型使用数据里能预测胜负的特征。标注偏好更长的回答，长度变成分数。高分回答共用同一个开头，开头变成分数。训练集里没有伪造引用，伪造引用不会被罚。

按 prompt 划分训练和验证，避免同一题的改写出现在两边。用更早的标注训练，用后来的标注验证。轮次增加后，随机划分上的准确率还可以，对抗改写先坏。

策略和奖励模型若只用同一批数据来回更新，两边会一起强化同一条捷径。留一份从不进入奖励模型训练的人工集。

## 5.4 策略梯度

状态 \(s_t\) 是 prompt 加上已生成的 token，动作 \(a_t\) 是下一个 token，策略就是语言模型。轨迹结束时拿到奖励。奖励来自程序或奖励模型，对采样出的离散 token 不可导。更新用

\[
\nabla_\theta J
=\mathbb{E}\Biggl[
\sum_t A_t\,\nabla_\theta\log\pi_\theta(a_t\mid s_t)
\Biggr].
\]

\(A_t>0\) 时提高该 token 的概率，\(A_t<0\) 时降低。\(A_t\) 是回报减去该状态的价值估计。减去价值不改变梯度的期望，方差下降。PPO 里的价值模型就是这个估计。

新旧策略的概率比

\[
r_t(\theta)
=
\frac{\pi_\theta(a_t\mid s_t)}{\pi_{\mathrm{old}}(a_t\mid s_t)}
\]

被限制在 \(1-\epsilon\) 到 \(1+\epsilon\)。相对 \(\pi_{\mathrm{ref}}\) 的 KL 项用来限制语言分布移走的距离。在线循环是：用当前策略生成，打分，更新若干步，再生成。旧轨迹用得越久，和当前策略差得越远。

一整条轨迹只有一个分数时，同一个优势会加到每个 token 上。错在中间一步，前面的 token 一起被压低。编译是否通过，测试进行到哪一步，这类中间结果可以单独给分。只看文字像不像推理的过程分，和最终结果一起用。

策略熵掉得太快，重复采样得到同一条回答，优势的方差一起消失。温度和熵项决定探索的宽度。温度过高时，轨迹过不了验证，生成成本还在。

## 5.5 GRPO

同一题从旧策略采样 \(G\) 条，得到 \(r_1,\ldots,r_G\)。组内标准化

\[
A_i
=
\frac{r_i-\operatorname{mean}(r)}{\operatorname{std}(r)+\epsilon}.
\]

高于组均值的轨迹优势为正。价值模型可以不训。概率比，clip，以及相对参考策略的 KL 仍然要算。

\(G\) 小，标准化的方差大。\(G\) 大，生成成本按 \(G\) 乘。一组里奖励完全相同，优势接近 0。全对和全错的题降低采样比例，另留一批固定题目，避免课程只跟着近期波动走。

格式分和正确性分分开记。格式分容易被固定模板拿满，加进总分之后会盖住正确性。

奖励改成程序：数值匹配，测试通过，证明检查器接受。这就是可验证奖励。验证器只抽最终数字，忽略单位；测试覆盖不全，硬编码样例也能过。策略更新会提高这些轨迹的概率。奖励上升时，用另一套不参与训练的检查看正确率。
