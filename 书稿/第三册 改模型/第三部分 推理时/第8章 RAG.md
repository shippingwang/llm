## 第 8 章 检索增强生成 RAG

ICL 解决的是让模型学会任务格式的问题，但无法解决模型不知道的事实知识问题。基座的知识截止到预训练时刻，后续新增的信息，垂直领域的专属知识，实时变动的数据，都无法通过预训练或微调实时同步。RAG（Retrieval-Augmented Generation，检索增强生成）就是为了解决这个问题而生：在推理时从外部知识库中检索相关文档，把相关知识拼入上下文，让模型基于检索结果生成答案，从根源上缓解幻觉与知识滞后问题。

### 8.1 RAG 的核心价值

RAG 的本质是外挂知识库 + 生成模型的组合，核心解决三类痛点：

1. **知识时效性**：可以随时更新外部知识库，让模型获取最新信息，不需要重新训练模型；
2. **领域知识注入**：企业内部文档，行业专属资料等预训练数据里没有的内容，可以直接接入知识库，无需微调；
3. **缓解幻觉**：模型输出严格基于检索到的原文，答案可溯源，可校验，大幅降低事实性错误。

和微调相比，RAG 的知识更新成本几乎为零，新增知识只需要向知识库新增文档，不需要重新训练，是动态知识场景的首选方案。

### 8.2 标准 RAG 全流程

一套完整的 RAG 系统分为离线索引与在线推理两大阶段，共五个核心步骤。

#### 第一步：文档预处理（离线）

把原始文档处理成适合检索的粒度，核心是**分块（Chunking）**：

- 原始文档通常很长，不能整段存入向量库，否则检索粒度太粗，无关信息太多；
- 按照固定长度，语义段落，章节结构等规则拆分成数百字的文本块；
- 分块策略是 RAG 效果的第一个关键节点：块太大容易引入噪音，块太小容易丢失上下文语义。

除了分块，还会做清洗，去重，格式标准化，剔除无意义的页眉页脚，乱码等内容。

#### 第二步：向量索引构建（离线）

对每一个文本块，用嵌入模型（Embedding Model）编码成固定维度的向量，存入向量数据库，同时保留原文内容。

- 嵌入模型的质量直接决定检索的准确率，是 RAG 系统的核心组件之一；
- 向量数据库负责存储向量并执行相似度检索，支持百万级以上的向量快速查询。

#### 第三步：召回检索（在线）

用户提问进来后，做两件事：

1. 用同一个嵌入模型把问题编码成向量；
2. 在向量库中做相似度匹配，召回 Top N 个最相关的文本块。

这一步叫**粗召回**，目标是尽可能把所有相关文档都找出来，允许少量不相关的结果混入，追求召回率。

#### 第四步：重排序（在线）

粗召回的结果数量多，精度有限，通常会再接一个**重排模型（Reranker）**：

- 把问题和每一个召回的文本块成对输入重排模型，输出相关性分数；
- 按照分数从高到低排序，只保留 Top 3~5 个最相关的块，送入后续生成环节。

重排是提升 RAG 准确率的关键一步，向量召回保证覆盖面，重排保证精准度。

#### 第五步：生成回答（在线）

把检索到的相关文档片段和用户问题一起拼入 Prompt，指令模型仅基于参考资料回答问题，最终输出答案。标准格式如下：

```
请根据下方参考资料回答用户问题，如果资料中没有答案，请说明无法回答。
【参考资料】
1. ...
2. ...

【用户问题】
...
```

模型输出的同时，通常会附带引用的资料来源，实现答案可溯源。

### 8.3 进阶 RAG 方案

基础 RAG 只能应对单轮，简单事实问答，面向复杂场景衍生出了多种进阶方案：

- **多轮对话 RAG**：加入查询改写模块，把多轮上下文整合成完整的检索问题，避免指代不清导致检索失效；
- **Self-RAG**：模型自主判断是否需要检索，需要检索几次，边生成边检索，适合复杂多步推理问题；
- **结构化 RAG**：除了文本向量检索，同时支持表格，图谱，数据库等结构化数据检索，融合多源信息生成答案；
- **分层检索**：先检索大的文档段落，再在段落内检索细粒度片段，兼顾上下文完整性与精准度。

### 8.4 适用边界与局限

RAG 不是万能的，它有非常明确的能力边界：

1. **只补知识，不改行为**：RAG 只能补充事实信息，无法改变模型的输出风格，格式，指令遵循能力，这类需求仍然要靠微调解决；
2. **依赖知识库质量**：知识库本身有错，不全，分块不合理，RAG 的效果会直接崩坏，垃圾进垃圾出；
3. **复杂推理能力弱**：需要跨多篇文档深度整合，多步逻辑推导的问题，仅靠检索拼接很难做好，这类场景更适合微调 + CoT；
4. **长上下文成本高**：检索到的资料全部要送入模型上下文，文档越多推理成本越高，延迟也越长。

行业通用的选型原则是：**动态事实，外部知识用 RAG；固定格式，行为规范用微调；快速验证，规则简单用 ICL**。三者不是互斥关系，工业级系统通常是三者组合使用。
