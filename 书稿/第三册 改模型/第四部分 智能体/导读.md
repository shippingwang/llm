# 第四部分 智能体

我们让模型研究一组资料，修复一段程序，或者完成一次跨页面操作时，任务通常需要多次判断。开始时的信息并不完整，模型需要先取得观察，再决定下一步；执行结果也可能与预期不同，原来的计划要随之修改。智能体方法首先要解决的，就是怎样把推理，行动与反馈组织成能够持续推进的过程。

第8章从逐步行动讲起，说明 ReAct 怎样使用每次返回的观察，再讨论计划式执行，反思，搜索和记忆。第9章继续说明动作怎样表达为工具请求或程序，以及 MCP 和 Skill 怎样提供可调用能力与可复用流程。第10章讨论运行这些过程的 harness，解释上下文，依赖调度，持久状态与中断恢复。第11章再把任务交给多个工作者，讨论角色协作，产物交接，以及多份判断怎样经过讨论与集成形成结果。

这些方法可以组合使用。一个模型可以先列出阶段计划，在局部采用 ReAct 执行，遇到失败后保存反思，再对独立分支安排工作者。理解它们时，可以沿着同一个过程观察：模型当前取得了哪些信息，为什么选择这个动作，执行后又怎样修改后续判断。
