# 第 11 章 harness

## 11.1 运行时

harness 是模型外面的运行时。它组装上下文，装载 Skill，检查并执行动作，记预算，写审计。模型产出 token。副作用由运行时放行。

没有这一层时，检索文本里的句子会被当成指令，未授权的工具会被调用，超时后的重试会造成重复写入，上下文变长之后把约束截掉。在提示词里加一句小心，这些行为仍会以一定概率出现。

## 11.2 状态

会话处于规划，执行，等人，结束中的哪一态，要能列出来。上下文按固定顺序拼：约束，当前启用的 Skill，取回的记忆，最新观察。文档和工具返回保持在低权限通道，不和约束混成一段。

## 11.3 网关

只执行名字在允许列表里，且参数通过 schema 的调用。执行前后留钩子，用来记审计和做幂等。步数，费用或延迟到阈值，进入事先写好的降级，循环停止。

形状由解码或 schema 保证。对象是否属于这个租户，请求是否重复，由运行时保证。库存和合规由业务服务保证。三层都过，动作才落下去。

每步留下输入摘要，动作，观察哈希，延迟和错误码。评测脚本固定任务，注入会失败的假工具，断言最终状态和调用序列。换一个模型接口，这层约束还在。
