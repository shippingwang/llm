# 第 11 章 评测框架 Harness

Harness 是面向智能体的标准化评测系统，提供统一的任务集，运行环境与评分规则，自动化完成多轮交互测试并输出量化结果，是智能体能力迭代的基础设施。

### 11.1 核心作用

普通静态评测只能衡量模型单次输出的质量，无法验证智能体多步交互，工具调用，环境适配的综合执行能力。Harness 通过模拟真实运行环境，端到端测试智能体完成任务的全流程，客观量化其真实落地能力。

### 11.2 核心组成

一套完整的智能体评测 Harness 包含四个模块：

1. **任务库**：标准化测试任务集合，覆盖不同类型与难度。每个任务包含明确的目标，初始环境状态与成功判定规则，涵盖工具调用，多步规划，代码执行，环境交互等典型场景。
2. **沙箱执行环境**：隔离的运行环境，提供代码执行，工具调用，系统交互等能力，保证评测过程安全可复现，不受外部环境干扰。
3. **交互调度器**：负责智能体与环境的全链路交互调度：将任务目标传递给智能体，接收动作指令并在环境中执行，回传执行结果，循环至任务结束或超时。
4. **评分报告模块**：依据预设规则自动判定任务成败，统计成功率，平均执行步数，工具调用准确率，错误重试率等核心指标，生成结构化评测报告。

### 11.3 核心评测维度

1. **任务成功率**：核心指标，即成功达成目标的任务占比；
2. **执行效率**：完成任务的平均步数，平均耗时，反映智能体的路径规划合理性；
3. **工具调用准确率**：技能选择正确率，参数格式正确率，反映工具使用的熟练度；
4. **错误恢复能力**：遇到执行错误后，能够自行修正并最终完成任务的比例；
5. **鲁棒性**：在输入模糊，环境变动，存在干扰的场景下，稳定完成任务的能力。

### 11.4 工业落地方式

工业界的 Harness 应用分为两类：

1. **通用基准评测**：采用公开标准基准集，横向对比不同基座，不同架构的通用能力，用于技术选型与基线验证。
2. **业务专属评测**：基于自身业务场景搭建定制化任务库，覆盖真实业务中的高频与边缘场景，作为版本迭代的回归测试基准。每次模型或架构升级后，通过 Harness 跑全量测试，量化评估效果变动。业务专属 Harness 与真实场景对齐度最高，是企业智能体体系的核心资产之一。
