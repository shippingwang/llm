# 第一部分 微调

深度学习模型理论里有一个非常重要的核心概念：模型表征具备可复用性。
2014 年的 R‑CNN 以及配套的一系列验证实验，改变了深度学习的训练范式：我们可以先训练一个通用底座，再在下游具体任务里复用它已经学好的参数，这套做法就是微调（finetune）。

微调让上下游任务的划分变得清晰，催生了分类，检测，分割等一大批任务导向的模型设计。有意思的是，同一时期 NLP 领域并没有很快走上这条路线；直到 BERT 出现，预训练 + 微调范式才在自然语言处理中广泛落地，统一了各类 NLP 任务。

到今天，大模型微调已经是算法工程师必备的技术。无论是受训练算力资源约束，还是业务需要快速迭代，学界的很多进展都围绕微调与后训练展开。
本部分我们介绍 SFT，蒸馏，思维链等技术，学习如何通过微调改善模型的输出表现。
