# 第 2 章 核心组件

这一章我们拆解 Transformer/注意力机制 的每一个组件

\[
\operatorname{Attention}(Q,K,V)
=\operatorname{softmax}\!\left(

\right)V
\]

## 2.1 注意力

相对于"Birds sing up in the tree" 的例子我们用一个更合适理解注意力机制的例子讲解。

这是一个顾客买衣服问尺码的场景。

顾客身高 170，体重 60。货架上有三张吊牌：

| 尺码 | 适合区间（用来比对） | 结论（对上后给出） |
|---|---|---|
| S | 155–165 cm / 45–55 kg | 穿 S |
| M | 165–175 cm / 55–65 kg | 穿 M |
| L | 175–185 cm / 65–75 kg | 穿 L |

三列分别对应三个角色：

- **Query \(q\)**：顾客拿来比对的条件——自己的 170 / 60。
- **Key \(k\)**：每张吊牌上的适合区间。
- **Value \(v\)**：对上之后交出去的结论：M


### 投影矩阵

这套 “查询 - 比对 - 取值” 的匹配逻辑，就是注意力的核心。Transformer不会直接用原始输入做比对：每一条待参与匹配的输入，都有隐藏状态 \(x\in\mathbb{R}^{d}\)。

> 在大模型里面，这些一个个比对单元，连起来就构成文本序列

原始输入乘三个可学习矩阵：

\[
q=xW_Q,\qquad k=xW_K,\qquad v=xW_V
\]

其中 \(W_Q,W_K,W_V\in\mathbb{R}^{d\times d_h}\)。

- **\(W_K\)**：把该位置编成挂在门口的标签，方便被点积比对（尺码例子里的适合区间）。
- **\(W_V\)**：把同一位置编成对上之后交出去的内容（尺码例子里的穿 M）。
- **\(W_Q\)**：把当前位置编成我带着什么条件去比

点积 \(q^\top k\) 要求 \(q\) 和 \(k\) 在同一套可比的坐标里；顾客的身材描述和吊牌上的区间描述虽然不是同一种写法，但是我们需要\(W_Q\) 与 \(W_K\) 映射进这个公共比对空间中。

这里我们关注两个设计问题：

1. 只有QK可以么？为什么用QKV这种检索方式建模？QKVV行不行？

标准 QKV 三元结构，来自 “相似度打分 + 加权聚合” 的最简数学配置，兼顾梯度形式与 GPU 张量规整性。它把 token 交互抽象成查询匹配，只是一个归纳偏置，不代表所有语义关系天然是检索关系。
可以构造单 QK 搭配多路 V 的变体（QKVV 等），能复用注意力权重，节约 QK 计算；但所有 V 共享同一套选择规则，自由度弱于多头独立 QKV，因此没有成为通用大模型主流。

2. KV看起来有很强的相似性，可以用一个矩阵编码，或者用一个小矩阵做转换？

Key 和 Value 绑定在同一张吊牌上，模型应该可以从 Key 直接学到 Value。理论上在理想情况下，模型确实可以学到 V 和 K 的映射关系。但如果强制让 \(W_V=W_K\)，等于强行规定：匹配用的索引表征，必须和输出用的内容表征是同一个线性空间。
Key 的优化目标是拉开相似度差距，它的表征优先服务打分；Value 的优化目标是聚合之后便于下游层理解，处理，表征优先服务信息传递。两套目标不完全一样。独立的 \(W_V\) 给了模型自由度
注意力输出，就是用相似度作为权重，对所有 Value 加权求和：分数决定关注谁，关注多少，最终流入网络的信息，全部来自 Value。
如果直接拿 Key 充当 Value，等于把 “比对用的索引” 当成输出内容，这个表征本身就不是为下游计算设计的，会损害表达能力。

随着训练，不同batch的投影矩阵不断更新，如果你对深度学习反向传播已经了解，大概会理解这里的投影矩阵是可学习参数的，随着反向传播一次次更新。当然，不去思考这个更新过程也没有问题，现在我们只讲清楚网络的前向过程。

### Softmax

Q K计算构成“查询”，进行计算后，产生三个原始点积分数。例如对 S / M / L 得到 \(s=(1.0,\ 4.0,\ 2.0)\)。
softmax负责将分数归一排序

\[
\alpha_j=\frac{e^{s_j}}{\sum_{j'}e^{s_{j'}}}
\]

上例近似 \(\alpha\approx(0.04,\ 0.84,\ 0.12)\)。注意力输出是

\[
o=\alpha_S\,v_S+\alpha_M\,v_M+\alpha_L\,v_L
\]

也就是：约 84% 取自穿 M，约 12% 取自穿 L，S 几乎不取。权重 \(\alpha\) 随 \(W_Q,W_K\) 训练

再看一遍Attention公式：

\[
\operatorname{Attention}(Q,K,V)
=\operatorname{softmax}\!\left(
\frac{QK^\top}{\sqrt{d_h}}+M
\right)V
\]


\(X\in\mathbb{R}^{n\times d}\)，单个头里 \(Q,K,V\in\mathbb{R}^{n\times d_h}\)，\(QK^\top\) 是 \(n\times n\) 分数表：第 \(i\) 行，第 \(j\) 列是位置 \(i\) 对位置 \(j\) 的原始分数。语言模型从左往右生成，算位置 \(i\) 时还不知道右边的词；若不加限制，位置 \(i\) 会直接去看 \(j>i\) 的 Key/Value，等于偷看尚未出现的 token。因果掩码 \(M\) 在 softmax 之前把这些 \(j>i\) 的格子写成 \(-\infty\)（分数表的严格上三角），softmax 后对应权重变成 0，于是每个位置只能看自己和左边。softmax 沿每一行做：第 \(i\) 行就是位置 \(i\) 对各个 Value 的取用比例。

再乘 \(1/\sqrt{d_h}\)。维度一高，随机向量点积容易偏大，softmax 会让分布变得又尖又硬，梯度不好回传。除以 \(\sqrt{d_h}\) 把分数拉回合适范围。

## 2.2 多头

子任务一般在深度学习神经网络架构中被抽象成“头”，而2.1只有一个头：每个位置得到 \(q,k,v\in\mathbb{R}^{d_h}\)，再做一张 \(n\times n\) 分数表。而多头是同一套隐藏状态，并行做 \(h\) 次这样的注意力，每次用自己的一套 \(q,k,v\)（维数仍是 \(d_h\)），最后把 \(h\) 个头的输出在特征维上拼起来，宽度不变：

\[
d=h\,d_h
\]

reshape 成

\[
Q,K,V\in\mathbb{R}^{n\times h\times d_h}.
\]

位置 \(i\)，头 \(t\) 上的三个向量就是

\[
q_i^{(t)},\ k_i^{(t)},\ v_i^{(t)}\ \in\mathbb{R}^{d_h},
\qquad t=0,\ldots,h-1.
\]

第 \(t\) 个头有自己的 \(W_Q^{(t)},W_K^{(t)},W_V^{(t)}\in\mathbb{R}^{d\times d_h}\)

用 \(n=4\)，\(d=8\)，\(h=2\)，\(d_h=4\) 看一下具体形状：

| 步骤 | 形状 | 含义 |
|---|---|---|
| \(X\) | \([4,8]\) | 4 个位置，每位置 8 维 |
| \(Q_{\text{all}}=XW_Q\) | \([4,8]\) | 一次投影出全部头的 Q |
| reshape | \([4,2,4]\) | 头 0 占前 4 维，头 1 占后 4 维 |
| 头 0 的 \(Q^{(0)}\) | \([4,4]\) | 只拿 \(Q[:,0,:]\) |
| 头 1 的 \(Q^{(1)}\) | \([4,4]\) | 只拿 \(Q[:,1,:]\) |

\(K,V\) 同样拆法。

头 \(t\) 内部与 2.1 完全相同：用该头的 \(Q^{(t)},K^{(t)},V^{(t)}\in\mathbb{R}^{n\times d_h}\) 算

\[
\operatorname{head}_t
=\operatorname{softmax}\!\left(
\frac{Q^{(t)}(K^{(t)})^\top}{\sqrt{d_h}}+M
\right)V^{(t)}
\in\mathbb{R}^{n\times d_h}.
\]

\(h\) 个头各有一张自己的 \(n\times n\) 分数表，互不共享注意力权重。头 0 可以主要对齐某类依赖，头 1 对齐另一类


每个位置上，把 \(h\) 个头的 \(d_h\) 维输出在特征维首尾相接，得到 \(d\) 维，再乘输出投影 \(W_O\in\mathbb{R}^{d\times d}\)：

\[
\operatorname{MHA}(X)
=\operatorname{Concat}(\operatorname{head}_1,\ldots,\operatorname{head}_h)\,W_O.
\]

两个 \(\operatorname{head}_t\) 各是 \([4,4]\)，Concat 得 \([4,8]\)，乘 \(W_O\) 仍是 \([4,8]\)，与 \(X\) 保持相同形状，现代模型常取 `head_dim=128`（也有 64，256）这个超参数由效果，RoPE 维数和 kernel 效率共同决定。

## 2.3 因果掩码

\(QK^\top\) 得到 \(n\times n\) 分数表后，在进 softmax 之前加上掩码 \(M\)：凡是查询位置 \(i\)，被看位置 \(j\)且 \(j>i\) 的格子（严格上三角），一律写成 \(-\infty\)。softmax 里 \(e^{-\infty}=0\)，这些位置的权重就变成 0——位置 \(i\) 看不见右边还没“轮到”的词。

训练时， `Birds sing up in the tree`，六个位置的 Q，K，V 和注意力在一次矩阵乘法里**一起算完**（并行），不是一个词算完再算下一个。但因果掩码保证信息仍只能从左往右流。每个位置 \(i\) 的输出用来预测**下一个**词 \(x_{i+1}\)：

| 当前位置（Query） | 允许看见的词 | 要预测的下一个词 |
|---|---|---|
| `Birds` | `Birds` | `sing` |
| `sing` | `Birds`, `sing` | `up` |
| `up` | `Birds`, `sing`, `up` | `in` |
| `in` | `Birds`, `sing`, `up`, `in` | `the` |
| `the` | `Birds`, `sing`, `up`, `in`, `the` | `tree` |
| `tree` | 整句六个词 | （句后再接什么，如结束符） |

所以：预测 `sing` 时只看 `Birds`
在训练时整句输入已知，六个位置的 K，V 在这一次前向里一次性算成整块张量，用因果掩码做完 \(n\times n\) 注意力就结束
推理时没有整句可并行：必须先写出 `Birds`，再据此采出 `sing`，再采 `up`……下一步的输入依赖上一步刚写出的词，所以只能串行。

## 2.4 FFN

注意力完成 token 之间的信息汇聚，它只是线性加权，缺少非线性建模能力。FFN 是作用在每个 token 上的前馈网络，所有位置共享权重，独立运算，不再发生跨 token 交互。


\[\operatorname{FFN}(x)=W_2\,\sigma(W_1x)\]

\(W_1\)将隐藏维d升维至4d左右，经过逐元素激活\(\sigma\)（GELU/SwiGLU 为主），再由\(W_2\)投影回d。非线性激活是 FFN 的关键，给模型带来线性聚合做不到的特征重组能力



## 2.5 残差连接

只有注意力和 FFN，还不能把层叠得很深，参考resnet

Transformer 用残差连接解决这个问题：记子层为 \(F\)（可以是注意力，也可以是 FFN），主干为

\[
x \;\mapsto\; x+F(x)
\]

子层只学习对原表示的增量；即便某一支暂时学得差，\(x\) 还在，下一层还能接着用。反向时梯度多了一条绕过 \(F\) 的恒等通路，深层才训得动。

残差要求 \(F(x)\) 与 \(x\) 形状相同，所以 FFN 最后要投回 \(d\) 维，注意力输出投影也要投回 \(d\) 维。


## 2.6 LayerNorm

层数堆多了之后，每一层的线性变换，激活输出，它的均值和方差会慢慢漂移。每一层微小的偏移不断叠加累积，传到深层的时候，特征分布已经偏离原本稳定的范围。这会造成训练时 loss 震荡，收敛困难，学习率很难调大；梯度时而爆炸，时而消失。

**LayerNorm** 对每个位置的 \(d\) 维向量单独做：减均值，除标准差，再乘可学习增益（可加偏置）：

\[
\operatorname{LN}(x)
=g\odot\frac{x-\mu}{\sqrt{\sigma^2+\epsilon}}+b
\]

它把向量尺度拉回稳定区间，与 BatchNorm 不同：统计量沿特征维算，不跨 batch，也不跨序列长度，所以变长序列，小 batch 也能用——序列模型里它比 BatchNorm 合适。


## 2.7 Post-LN

现在看下 层之间的拼接顺序

2017 年原版把 Norm 放在残差**相加之后**，称为 Post-LN（post-normalization）：

\[
H=\operatorname{LN}\!\big(X+\operatorname{Attention}(X)\big),
\qquad
Y=\operatorname{LN}\!\big(H+\operatorname{FFN}(H)\big)
\]


## 2.8 绝对位置编码

注意力机制本身按内容匹配 token，没有顺序感知能力。如果不注入位置信息，“先去西湖再去灵隐” 与 “先去灵隐再去西湖”，在它眼里只是同一组词。因果掩码仅仅控制能不能看到右侧 token，只提供 “可见 / 不可见” 的二元约束，无法区分两个 token 之间相隔 3 个还是 300 个 token。因此序列顺序必须通过位置编码显式注入模型。

绝对位置编码：为每个下标 \(t=0,1,\ldots\) 准备一个 \(d\) 维向量 \(\mathrm{PE}(t)\)，加在词嵌入上：

\[
h^{(0)}_t=E[x_t]+\mathrm{PE}(t)
\]

正弦余弦编码：对位置 \(\mathrm{pos}\)（第几个 token，从 0 起），维度下标 \(2i\) 与 \(2i+1\)（\(d\) 为向量总维），

\[
\mathrm{PE}_{(\mathrm{pos},\,2i)}=\sin\!\bigl(\mathrm{pos}/10000^{2i/d}\bigr),\qquad
\mathrm{PE}_{(\mathrm{pos},\,2i+1)}=\cos\!\bigl(\mathrm{pos}/10000^{2i/d}\bigr).
\]

不同维度对应不同频率，不增加可训练参数；

也可以改成一张可学习的位置嵌入表，用到哪个位置就查哪一行。

- 正弦 PE：向量由三角函数公式生成，不可训练，天生支持外推（训练最长 512，推理到 1024 也能算）
- 可学习位置表：向量是查表查出来的可训练参数。缺点：表的行数是预先定死的，训练最多学到位置 512，推理超过 512，表里没这一行，直接没法用，外推很差

> 外推 = 模型训练时只见过最长 L 长度的句子，推理的时候，让它处理比 L 更长的句子

当然，今天开源稠密模型几乎不再把绝对位置加在嵌入上，而是改成在注意力里旋转 Q/K（RoPE）。在第6章再详细介绍。

## 核心问答

**Q1：为什么要除以 \(\sqrt{d_h}\)，不是别的数？**
\(d_h\) 维独立随机向量点积的方差正比于 \(d_h\)，除以 \(\sqrt{d_h}\) 恰好把方差拉回 1 量级，使 softmax 工作在梯度健康的区间。我们在第 0 章分析过这件事情。

**Q2：多头会让模型变慢吗？**
基本不会。多头是把 d 维切成 h 份分别算，总 FLOPs 与单头相同，只多了一次 reshape 和最后的输出投影。代价在实现复杂度和访存模式上，不在算力。

**Q3：FFN 为什么占了大部分参数？**
标准 FFN 把 d 升到 4d 再降回来，参数量约 8d²；注意力四个投影矩阵合计约 4d²。所以 FFN 约占每层的三分之二。

**Q4：残差和 LayerNorm 能不能只留一个？**
浅网络有时能凑合。层数一多，两边都要：残差解决梯度有路可走，LayerNorm 解决数值稳定性。只留残差，尺度仍可能训崩；只留 Norm，没有残差，同样难训。
