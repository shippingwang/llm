# 第二册 大模型训练与推理系统

**读者**：已经读懂第一册模型架构，希望真正进入大模型训练，推理与部署工作的算法或系统工程师。

**读完能做到**：

1. 说清一块 GPU 里计算和存储怎样分层，一段 CUDA kernel 大致怎样被调度；说清一个训练 / 推理集群的节点内互联和节点间网络长什么样。
2. 给定模型，GPU 集群和训练 token 数，设计一套能算出每卡显存，通信量和预计 MFU 的并行训练方案，并说清作业怎么提交，检查点写到哪，挂了怎么续。
3. 看懂 Megatron，DeepSpeed，FSDP，vLLM，SGLang，TensorRT-LLM，LMDeploy 一类系统各自在解决什么问题，以及它们和并行 / KV / 调度机制怎样对应。
4. 从一次请求进入服务开始，解释它如何排队，分配 KV，跨卡执行并逐 token 返回，并用 profiler / 指标定位它慢在哪一段。
5. 正确评测吞吐，首 token 延迟，逐 token 延迟和服务成本；完成权重格式转换与灰度切换。

## 本册边界

- 第一册“**做模型**”：GQA，MLA，MoE，线性注意力，MTP 为什么存在。
- 第二册“**跑模型**”：GPU 与集群硬件，CUDA 基础，并行与训练框架，推理机制与引擎，量化与算子，观测与交付。
- 第三册“**改模型**”：SFT，LoRA，DPO，RLVR，工具和 Agent；本册只写后训练需要的 rollout / 权重同步系统，不写对齐损失。

第一部分会讲 GPU 架构，CUDA 和集群结构，目标是读得懂后续并行，通信和 kernel 讨论，并会做基础 profiling。不写成独立的 CUDA 认证教程：不系统讲全部 API 与全部优化套路；需要手写 / 深改 kernel 时，在第 31 章再回到融合与编译栈。

机制章先讲为什么要这样切，这样调度；框架 / 引擎章再讲现成系统把哪些机制做成了产品。

## 第一部分 硬件，CUDA 与集群

- **第 1 章 GPU 架构**：SM，warp，Tensor Core，寄存器 / shared / L2 / HBM；算力与带宽两本账；为什么 Decode 常被 HBM 卡住
- **第 2 章 CUDA 执行模型**：grid / block / thread，内存类型，占用率，stream 与异步；和 PyTorch 算子怎么对上；读一段 attention / gemm 相关代码时看什么
- **第 3 章 单机多卡与节点**：PCIe，NVLink / NVSwitch，CPU 亲和与 NUMA，一张节点示意图要能画出来
- **第 4 章 集群架构与网络**：机柜与 leaf-spine，rail-optimized，InfiniBand / RoCE，NCCL 域；训练集群和推理集群在拓扑上常见差异
- **第 5 章 集合通信**：AllReduce，AllGather，ReduceScatter，AllToAll；带宽时延模型；和拓扑怎么匹配
- **第 6 章 训练显存构成**：权重，梯度，优化器状态，激活，临时张量，碎片；重计算与梯度累积怎样换显存
- **第 7 章 混合精度与数值稳定**：FP16 / BF16 / FP8，损失缩放；训练精度和推理精度分开记账
- **第 8 章 性能模型与 profiling**：算术强度，Roofline，kernel 启动开销，通信重叠；Nsight Systems / Nsight Compute / PyTorch Profiler 怎么用

## 第二部分 分布式训练机制

- **第 9 章 数据并行与梯度同步**：DDP，全局 batch，梯度桶，加卡为何不线性
- **第 10 章 ZeRO 与状态分片**：三阶段分片，参数生命周期，预取与 CPU / NVMe offload
- **第 11 章 张量，序列与上下文并行**：TP，SP，CP（含 Ring / Ulysses 一类思路），packing 的静默坑
- **第 12 章 流水线并行**：气泡，1F1B，交错调度，与 TP / DP 的配合
- **第 13 章 专家并行与 MoE 训练**：AllToAll，token dispatch，负载不均
- **第 14 章 多维并行怎么配**：从显存和带宽约束倒推，拓扑映射，MFU 与 HFU

## 第三部分 训练框架，数据与集群工程

- **第 15 章 训练框架对照：Megatron，DeepSpeed，FSDP**：各自主线，配置怎样映射到第 9–14 章，Accelerate 等入口层，选型判据
- **第 16 章 优化器与训练配方**：AdamW，Muon 等，显存占用，与并行策略的接口，常用超参日程
- **第 17 章 预训练数据工程**：质量过滤，去重（MinHash 等），混合配比，token 预算；和第三册偏好 / SFT 数据的分工
- **第 18 章 数据加载与打包**：dataloader，packing，序列长度分布，吞吐被数据卡住时怎么查
- **第 19 章 检查点与权重流转**：保存格式，异步持久化，Megatron / HF / 引擎之间的转换，safetensors 与版本管理
- **第 20 章 集群作业，存储与容错**：Slurm / K8s / Ray 提交与亲和，共享存储带宽，故障谱系，弹性续跑，Goodput，实验追踪（W&B 等）

## 第四部分 推理机制

- **第 21 章 请求生命周期与指标**：Prefill / Decode，TTFT / TPOT / ITL / 吞吐，开环压测怎么做
- **第 22 章 KV Cache 与 PagedAttention**：碎片，分页，写时复制；前缀缓存；分层 / 卸载 KV
- **第 23 章 连续批处理与 Chunked Prefill**：迭代级调度，token 预算，抢占与公平，显存准入
- **第 24 章 多 GPU 推理与 PD 分离**：TP 收益拐点，MoE 推理，多副本，Prefill / Decode 分离与路由
- **第 25 章 投机解码的系统实现**：接受长度，草稿来源，树状验证，与大 batch 的冲突

## 第五部分 推理引擎与后训练系统

- **第 26 章 推理引擎对照：vLLM，SGLang，TensorRT-LLM，LMDeploy**：PagedAttention / RadixAttention，调度与图编译；结构化输出与多轮前缀；按场景选型
- **第 27 章 引擎落地与多租户**：单机多卡，多副本，PD 分离；LoRA / 多适配器服务；前缀缓存感知路由；和网关怎么接
- **第 28 章 后训练系统：Rollout 与权重同步**：采样池与训练池怎么摆（含 verl 一类资源映射），策略版本，权重下发；对齐算法见第三册

## 第六部分 压缩，算子与执行后端

## 第七部分 评测，观测与交付

## 三条贯穿场景（正文共用）

正文开写后，各章尽量回到同一组假设上填表，避免每章换一套模型。

1. **预训练**：大参数稠密或 MoE，多机多卡，关心并行切分，MFU，检查点与故障恢复。
2. **在线推理**：中大参数服务，关心 TTFT / TPOT，KV 池，连续批，引擎与副本。
3. **后训练 rollout**：训练池 + 采样池，关心权重同步，资源比，策略版本。

具体卡型，参数量，上下文和 SLO 在第 1 章末钉死一版，后续章只声明相对该基线改了什么。

## 贯穿全书的两份产物

- **一张资源表**：每次引入并行，分片或压缩，都重算每张卡上的参数，梯度，优化器，激活，KV 和通信量。
- **一条请求时间线**：每次引入调度，缓存或引擎特性，都重新标出排队，Prefill，Decode 和通信各花了多久。

另加一份贯穿训练侧的 **作业与故障记录**：并行配置，存储路径，失败原因，恢复耗时，Goodput。
